# PBL 教案生成器（PBL Lesson Builder）

**阶段 2**：把「已盘对的知识点」转成一份**可直接落地**的 PBL 教案。它**不负责澄清**——必须先由 `knowledge-point-clarifier` 完成澄清盘对，拿到五项交接物后本 skill 才接手。若输入的知识点尚未盘对，应退回澄清阶段。

## 前置条件（handoff contract）

本 skill 开工前，必须已具备以下五项（缺失即请先澄清，不要编造）：
1. 知识点的**准确定义**
2. **边界**（什么算、什么不算 / 易混淆点）
3. **目标对象**：年龄 / 年级、场景（家庭 or 课堂）、人数、当前起点
4. **行为化学习目标**：学后能做什么 / 说清什么
5. **约束**：时长、材料/工具/场地限制、需避免的点

## 教案输出结构（8 模块，按序）

### 1. 项目概述
- 项目名称（围绕知识点、孩子能懂的有趣名字）
- **驱动问题**（Driving Question）：开放、真实、有挑战
- 对象 / 预估时长 / 场景 / 人数

### 2. 学习目标
- 知识目标（掌握什么）
- 能力目标（批判思维、沟通、协作、创造）
- 情感/态度目标

### 3. 分阶段里程碑（3–5 个阶段）
每阶段含：
- 阶段目标
- 具体活动/任务（家长/老师引导话术 + 孩子动作）
- 所需材料（就地取材，标注替代品）
- 阶段产出（推动最终产出）

### 4. 引导策略
家长/老师是 **facilitator** 不是讲解者。给 5–10 个「脚手架问题」示例。

### 5. 最终产出与展示
- 最终作品描述（海报 / 模型 / 演示 / 报告 / 视频…，贴合对象与约束）
- 展示方式（向家人/同学介绍，含 Q&A）

### 6. 评价 Rubric
维度（探究深度 / 作品质量 / 表达 / 协作）× 等级（优 / 良 / 待改进）。用孩子和家长都能懂的语言，强调"学到了什么"，不只打分。

### 7. 家庭/课堂适配 + 难度分级
- 家庭：单人改亲子协作；材料简化
- 课堂：分组建议、时间分配
- 低龄（简化）与高龄（加深）调整

### 8. 扩展与下一步
1–3 个延伸项目/话题，鼓励继续探究。

## 撰写原则

- **驱动问题必须是"真问题"**：不是"什么是 X"这种可检索的，而是"我们怎样用 X 解决/做出…"。
- **孩子是主角**：孩子动手、试错、提问；家长/老师引导。
- **跨学科**：尽量链接至少一个其它学科（数学/语文/艺术/科学/社会）。
- **就地取材**：优先家里/教室现成物品，给替代方案，照顾普通家庭。
- **尊重年龄**：语言、复杂度、自主度匹配年龄段；含分级调整。
- **忠实交接物**：时长、人数、场景、边界、目标都严格按阶段1盘对结果来，不擅自改动。
- **基于框架**：黄金标准 PBL（PBLWorks）驱动问题、持续探究、真实性、学生声音、反思、公开展示。

## 完成判据

教案齐备 8 模块、且与五项交接物一致、达到"家长/老师可直接照着带孩子做"的程度，即算完成。完成后把定稿教案（含封面信息）作为交接物交给下一阶段。

## 衔接

定稿后可问：「教案已完成。需要我把它导出成文档 / PPT 吗？」——导出由 `pdf` / `pptx` / `html-ppt` skill 负责（阶段3）。
